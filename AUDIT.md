## D. Currently broken / unsafe (found in this audit)
1. `board.py` silently drops every 3-way market (`len(sides) != 2`), so soccer is invisible, not "no edge".
2. `board.same_team` has no confidence, no ambiguity check and no identity flags (a bare "New York" could pair with either NY team).
3. The cloud collector and `status.py` cover 6 hard-coded leagues only.
4. Six Pinnacle categories (Chess, Darts, Golf, Handball, Rugby, Snooker) return 403 to the guest API even after backoff.
5. The first alias table leaked across sports ("Washington" → Commanders would have blocked the Nationals); fixed via sport-scoped aliases and tests.
