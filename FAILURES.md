## 2026-09-29: daily paper Kalshi pick crashed at 15:00; re-run 15:28 ET
- Symptom: `kalshi_pick failed: TypeError('NoneType' object is not subscriptable)`; no KALSHI_SINGLE row at 15:00.
- Root cause: `quality.assess` built the stale-list label from a health row that was None (series with no heartbeat, e.g. KXARGNACBGAME), so it crashed instead of flagging stale. Fixed: missing heartbeat = NO_HEARTBEAT = stale.
- Recovery: KALSHI_SINGLE re-run manually at 19:28Z (28 min late) with the fixed code; no other rule changed. Pick: Eritrea YES @ 0.09, EV -7.2%, NEGATIVE_EV (also a YES < 0.20 longshot, hard-banned for real money).
- Latent bug also fixed: the launchd job checked `date +%H` = 15 AFTER a ~21-min registry build; a >60-min build would silently skip the pick. Hour is now captured at job start.

## 2026-09-30: cloud D1 blew the free rows-read limit (7.0M/24h vs 5M/day); cloud collector stopped ~12:02Z
- Bryan saw "91% used" on the Cloudflare dashboard. `wrangler d1 info`: rows_read_24h 7,047,513.
- Root causes: (1) every 1-min run did `max(ts) FROM collector_runs GROUP BY league, source` = full scan of the growing run log (~2.9k rows/min, ~4M/day); (2) ended markets stayed in `latest` as k='gone' and were re-read by every per-league lookup (3,298 of 7,710 rows).
- Fix: `last_ok` table (66 rows) upserted on success; ended markets deleted from `latest` (the snapshot gone-marker is still written). Backfilled last_ok, purged gone rows, redeployed; first run after deploy OK.
- Risk noted: D1 limits are account-wide, so hitting them would also have broken the dabbelt-crm database.

## 2026-10-01: p_at priced tonight's legs from LAST WEEK's Pinnacle line
- Symptom: Blake Whiteheart MORE 0.5 receptions showed 59.2% on the TNF board; Kalshi's same-night 1+ rung said 48.5%.
- Root cause: `stale_scan.p_at` took the latest Pinnacle row for that player/stat with no event check, so the 2026-09-27 game's price (-163/+134) was used for 2026-10-01. Also ignored gone-markers (NULL price) and priced pulled markets from their last quote.
- Fix: Pinnacle and Kalshi lookups now require start_time >= t - 6h (this game only); gone-markers respected. Shared function, so it covers daily_paper, stale_scan, stale_followup.
- Exposure: daily_paper picks 09-28..10-01 used same-day prices (checked 09-30 and 10-01 legs); H12 detected 0 legs, so no logged result relied on a stale price. Caught BEFORE any slip was placed.

## 2026-10-01: NFL settlement couldn't tell 0 catches from inactive
- ESPN's box score lists only players with a stat in a category, so a receiver who played with 0 catches had no row: LESS legs on him never settled and calibration had to be shown two ways.
- Fix: `prop_settle.played()` reads the game roster (ESPN core API `didNotPlay`) and zero-fills receiving/rushing stats for players who played; DNP stays missing (PrizePicks voids). Verified on MNF: 6 DNP players still unsettled, 0-catch players settle as 0.
- Ceiling: ESPN's flag is per game, not per snap; a dressed player with zero snaps may still show didNotPlay=False.
